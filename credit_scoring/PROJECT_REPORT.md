# Project Report: Credit Scoring Model

## Introduction
Credit scoring is a classification problem that uses applicant information to estimate whether a credit application may be approved.

## Objective
To build a beginner-friendly machine-learning pipeline using financial and repayment-related features.

## Methodology
1. Load the CSV dataset using Pandas.
2. Separate input features and target label.
3. Split the data into training and testing sets.
4. Handle missing numeric values with median imputation.
5. Train a Random Forest classifier.
6. Evaluate predictions using accuracy, precision, recall, F1-score and a confusion matrix.

## Inputs
Age, annual income, employment years, loan amount, existing debt, late payments and credit history years.

## Output
A demo prediction of likely approval or likely non-approval.

## Conclusion
The project demonstrates how classification algorithms can be applied to financial-style data. The dataset is synthetic, so this project is for learning only and is not suitable for real credit decisions.
