# CodeAlpha Tasks — Machine Learning

This repository contains two CodeAlpha internship task implementations:

1. Credit Scoring Model
2. Heart Disease Prediction Model

Each project folder contains a CSV dataset, training script, Streamlit app, requirements file and README.

## Setup
Open a terminal in the project folder:
```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

**Dataset note:** Both CSV files in this submission are synthetic educational datasets generated for demonstrating the ML workflow. They are not real financial or medical records. The results should not be used for actual lending or medical decisions.
