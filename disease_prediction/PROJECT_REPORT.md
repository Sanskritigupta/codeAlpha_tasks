# Project Report: Heart Disease Prediction

## Introduction
Machine learning can demonstrate how patterns in structured health-related data may be used in a classification task.

## Objective
To build an educational model that predicts a heart-disease label from selected input features.

## Methodology
1. Load the CSV dataset using Pandas.
2. Separate input features and target label.
3. Split the data into training and testing sets.
4. Handle missing numeric values with median imputation.
5. Train a Random Forest classifier.
6. Evaluate predictions using accuracy, precision, recall, F1-score and a confusion matrix.

## Inputs
Age, sex encoding, chest-pain type, resting blood pressure, cholesterol, fasting blood sugar, maximum heart rate, exercise-induced angina and oldpeak.

## Output
A demo risk-pattern classification.

## Conclusion
The project demonstrates a basic machine-learning workflow. The dataset is synthetic and the model is not a medical diagnostic tool.
